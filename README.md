# F1 Era Timeline 🏎️

The **F1 Era Timeline** is a visually stunning, comprehensive archive of 75 years of Formula 1 history (1950 — 2026). This application allows users to explore every constructor that ever raced, every driver who ever competed, and every championship ever won across the different technical eras of the sport.

## ✨ Features

- **The Complete Archive:** Browse seamlessly through every F1 season, team, driver, and circuit.
- **Era Exploration:** Dive into the distinct technical eras of F1 (Pre-Turbo, Turbo, Atmo, V8, and Hybrid Eras).
- **Rich Detail Pages:** Discover in-depth statistics, race wins, podiums, and championship histories for individual drivers, constructors, and circuits.
- **Premium Aesthetics:** Features a bold, high-contrast UI using *Barlow Condensed* typography, dynamic scrolling marquees, and curated team color accents.
- **Live Statistics:** Real-time data aggregation directly from the database for accurate race counts and championship records.

## 🛠️ Technology Stack

- **Frontend:** React + Vite
- **Styling:** Vanilla CSS with custom CSS variables for easy theming and responsive design.
- **Database:** Supabase (PostgreSQL) for blazing-fast, paginated data retrieval.
- **Routing:** React Router DOM 

## 🎨 UI & Design Language

The app uses a consistent design language inspired by the speed and energy of motorsport:
- **Typography:** Heavy use of Google Fonts' `Barlow Condensed`.
- **Dynamic Elements:** CSS-powered infinite scrolling text marquees for hero headers.
- **Layouts:** Left-aligned, structurally balanced grid systems with subtle glassmorphism and modern masking effects.

## 📝 Data Source
Data is aggregated and provided via Jolpica. This project is a fan-made archive and is not affiliated with the FIA or Formula 1.
